## Воспроизводимость
- Все случайные процессы засеяны (`SEED = 42`): Python, NumPy, PyTorch.
- Порядок батчей фиксируется через `torch.Generator(seed=SEED)`.
- ARIMA-порядок подбирается **один раз** на Train (без подглядывания в Test).
- Масштабирование выполняется только по Train.
- Разделение Train / Validation / Test — хронологическое, с зазором не менее горизонта (2880 мин).
- Версии пакетов зафиксированы в `requirements.txt`.
- Запуск на чистом окружении не требует ручных правок.

## Примечания
- LSTM и GRU показывают сопоставимое качество (разница по MAE ≈ 0.47), корректно говорить о паритете архитектур, а не о строгом превосходстве.
- Минутный ряд получен интерполяцией дневных значений, поэтому модели обучаются на искусственно «сглаженном» ряде без реальной внутридневной динамики. Результаты следует интерпретировать как эксперимент на учебном ряде.
- ARIMA-порядок `(2, 1, 2)` выбран по AIC на Train (AIC = 15285.12).
